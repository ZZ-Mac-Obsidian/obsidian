# Publish Checklist

Check each item against the current Roblox pages before relying on it; several changed during 2026.

## Account, once

- [ ] ID verification and 2-step verification on the creator account
- [ ] Group created to own the games (members and milestone rewards live here)
- [ ] Payout details set up

## Before publishing a game

- [ ] Name searched on Roblox; not taken, not confusable with a hit
- [ ] Maturity and compliance questionnaire completed (aim for Minimal or Mild)
- [ ] No free-form drawing or social-hangout features (these are excluded from the under-16 catalogs)
- [ ] Custom thumbnail uploaded (a default thumbnail gets no Home impressions)
- [ ] Icon, 3 to 5 thumbnails with personalisation switched on, 15 to 30 second gameplay video with no spoken audio, all passing the checklist in [[17 - Icons Thumbnails and CTR]]
- [ ] Listing matches the gameplay and does not resemble an existing game's title, images or place file
- [ ] Regional pricing switched on for developer products; no prices hard-coded in the interface
- [ ] Offline earnings, daily reward and welcome-back screen tested across a real overnight gap
- [ ] Description says what you do in one line; no promises of free Robux or giveaways
- [ ] Passes and products created, tested with a real purchase, descriptions exact
- [ ] Random items (if any) show odds and respect regional restrictions
- [ ] Private servers set to free
- [ ] Analytics events firing; tutorial funnel visible
- [ ] Tested on phone, tablet, PC, controller; four players together
- [ ] Fresh-save playthrough timed against the early-wins table
- [ ] Saving survives leaving mid-area and a server shutdown
- [ ] credits.md complete

## Reaching under-16 players

Roblox splits accounts into Kids (5 to 8), Select (9 to 15) and Roblox (16+). New games start with age-checked players aged 16+ and must qualify to reach younger ones (official, read 11 Nov 2026; this has changed several times, so read the live page).

- [ ] Account in good standing, age-verified, 2-step verification on
- [ ] Content questionnaire result of Minimal, Mild or Moderate
- [ ] Pay the one-time refundable fee (reported as 1,000 Robux; refunded 90 days after the game becomes eligible), or hold Roblox Plus or Premium for 2 consecutive months
- [ ] Reach 250 unique plays by highly engaged age-checked users within 60 days
- [ ] Pass the evaluation
- So the first audience is 16+: the game must look good enough for them first.

## Launch day

- [ ] Publish on a Friday afternoon; Home traffic peaks on Saturdays
- [ ] Share link created for all outside promotion (pays 35% of new users' early spend)
- [ ] Nominate for Standout Games if the game is genuinely new
- [ ] Small ad campaign started (see [[06 - Marketing Playbook]])

## Days 1 to 14

- [ ] Check bounce, day-1 return and session length daily
- [ ] Fix the worst tutorial step first
- [ ] One visible update in week one, announced in the group ([[22 - Live Ops and Updates]])
- [ ] Day 14: keep, fix or kill using [[00 - Start Here]]
